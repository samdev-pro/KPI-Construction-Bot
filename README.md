📊 Construction KPI Bot

The Construction KPI Bot is a Python-based tool that demonstrates how to collect, analyze, visualize, and report on key project metrics. It showcases practical skills in:

Data Handling → using pandas for cleaning and analyzing project data

Visualization → using matplotlib to generate clear KPI charts

Reporting → generating professional PDF reports with tables and graphics

Automation → sending reports automatically via email

This bot can be easily adapted to real-world project management scenarios, where quick KPI insights and automated reporting are essential.

✨ Features

Import project data from CSV files

Calculate KPIs such as:

Budget variance

Schedule % complete

RFIs (open vs closed)

Safety incidents

Generate charts for Schedule Completion and Budget Variance

Create a PDF report that includes:

Project summary tables

KPI charts stacked neatly on the same page

Automatically email the report to recipients
